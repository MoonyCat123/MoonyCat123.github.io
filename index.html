stdio.h 文件是一个头文件 (header, 文件拓展名为 .h). 通常, 在 C 程序顶端的信息集合被称为头文件, 包含着编译器为编译程序可能需要用到的信息, 包括声明变量以及声明函数. 在 stdio.h 文件中, 包含着 printf() 的函数声明, 这是我们需要的, 因此这里我们需要使用这条语句.

事实上, stdio.h 被称为标准输入/输出头文件, 它包含 C 函数库中输入/输出函数的声明, 在绝大多数需要输入输出的程序中都需要用到它.

在 C 程序中你可以定义任何函数, 但记住, main() 函数总是程序首先执行的函数, 看来 main 这个普通的名字对编译器有着特殊的意义 XD.

C 程序的基本模块是函数, 每个函数有着各种各样不同的功能, 而 main() 函数总是最先被执行的函数, 它是程序的基本框架.

这行代码叫做声明, 声明是 C 最重要的特征之一. 在其他语言中, 你可能不需要这行代码就能直接使用一个变量, 但 C 语言严格化了使用变量这个操作, 对于以简便灵活著称的 C 语言, 这么做一定有道理.

声明中的 int 告诉了计算机我要使用一个整形变量, 计算机便在内存中的某个位置划分出整形所需要大小的内存区域, 并将该内存区域命名为 num, 以后每当程序使用 num 这个变量, 就会查取这个内存区域所存储的值.

printf()函数

printf()是标准输出函数, 这个函数会查看双引号中的内容, 并将其打印在一个窗口上. 除了一些能明确输入的字符, 还有一些不能直接输入的字符 (转义序列), 比如换行符. 输入\n 能表示这个符号, 使得光标换行再继续输入.

第三条 printf 语句不仅打印了一系列我们输入的字符, 还打印了 num 变量的值. 在打印变量的值时, 计算机会用变量的内容替换掉 %d. %d 中的 d 告诉计算机, 我想用十进制整数的形式来打印出 num 的值, 以后还会见到更多变量的输出形式.

上面说过, int main(void) 中的 int 表示 main() 函数的返回值为整形, 那返回值为多少呢? 使用 return 语句来返回函数的值, 这里返回的值为0. 对于有返回值的函数 (函数名前的返回值类型不是 void 的函数), 都需要 return 语句来返回函数值.

这里 main() 函数的返回值其实没有太大的含义, 但 C 语言要求如此, 一般都会在 main() 函数主体最后加上 return 0. (如果没有 return 语句, 函数默认返回值也是0, 但其他有返回值的函数返回值都是有意义的, 都需要最后加上 return 语句, 这里为了养成好习惯, 所以在 main() 函数最后也加上)

注释有两种形式, 可以用 / … / 将注释内容括起来, 相当于括号, 可以跨行使用. 另一种是 // , 注释内容放于其后, 只能单行使用.

定义函数

函数是 C 程序的基本模块, 每个函数都有各种各样的功能. 函数由函数头和函数体组成, 函数头包括返回值类型, 函数名以及传入函数的信息类型, 函数体即为花括号部分. 函数体由一系列语句 (如运算表达式, 赋值表达式等) 和声明(变量的声明) 组成.

分号是一条语句和一条声明的一部分, 当编译器读到分号时, 编译器明白这是一条语句, 写程序一定不要忘记分号. (语句以分号为分隔, 即使你将所有语句写在同一行, 只要加上了分号, 代码也能运行, 只是会不那么美观. 预处理指令以换行符为分隔, 不需要分号) 函数声明也是声明, 也是一条语句, 需要使用分号. 定义函数时, 函数头与函数声明很类似, 但函数头后面不能使用分号, 因为它不是一条语句.

我们定义的 apple 函数返回值类型为 void, 即没有返回值, 因此没有 return 语句.

程序的调试

程序调试过程即为发现程序错误并修改的过程. 如果程序有语法错误, 编译器能够发现并指出.但如果发生语义错误, 编译器则不能发现.

如果在编译过程中发生错误, 根据编译器的提示检查代码对应行, 改正语法错误.

如果编译成功, 但输出结果和预期不符 (即发生语义错误), 对于简单的程序, 可以逐条分析代码, 模拟变量变化过程, 分析变量在哪一步发生了问题. 对于较为复杂的程序, 可以利用编译器自带的调试工具. 调试工具能使代码运行至指定位置, 并逐条运行代码, 在运行过程中你可以查看变量的变化过程.

在学习 C 语言时, 犯错是不可避免的, 不要灰心, 这些都能成为你宝贵的经验!

C Primer Plus

初识C语言

C语言是一门流行的语言,融合了计算机科学理论和实践的控制特性. C语言的设计理念让用户能轻松地完成自顶向下的规划, 结构化编程和模块化设计. 因此, 用C语言编写的程序更易懂, 也更可靠.

C语言的优点

  1. 代码紧凑且运行速度快, 十分高效
  2. 可移植性强, 在一种系统写的C程序稍作修改或者不修改就能在其他系统上运行
  3. 强大而灵活
  4. 面向程序员. C语言是为满足程序员需求而设计出来的, 在C语言中程序员甚至可以访问硬件, 控制内存中的位.

C语言的缺点

C语言足够灵活, 它不像其他语言那样要求严格, 给予了程序员很大的自由, 但同时也增加了犯错的风险. 特别是指针的使用, 涉及指针的编程错误往往难以察觉.

计算机能做什么?

在学习如何使用C语言编程之前, 最好先了解一下计算机的工作原理, 这有助于理解从C语言编写到运行发生了什么.

计算机由许多部件组成, 其中CPU(中央处理单元)承担绝大部分的运算工作, 而所要执行的程序储存在内存中.

CPU工作很简单: 从内存中读取一条程序, 执行, 读取下一条程序. CPU中有许多寄存器, 每个寄存器都能存储一个数字(这个数字的最大值根据寄存器的位数确定). 其中一个寄存器储存CPU下一条要执行的指令的地址, CPU根据该地址来获取和更新下一条指令, 并将其放在另一个寄存器中. 同时, 存放地址的寄存器更新下一条指令的地址, 诸如此类.

CPU能理解的指令不多, 而且这些指令相当具体, 其中很多都是用于请求计算机将数字由一个位置转移到另一个位置, 如从内存转移到寄存器中, 并且, 这些指令都需要用数字指令码来表示(机器语言). 在书写这种指令时, 要清楚知道需要CPU具体做什么.

用机器语言书写代码是枯燥乏味的, 且可读性很差. 高级编程语言(如C语言)以很多方式来简化了编程工作. 首先, 不必再使用数字指令来编程, 一种能很好体现逻辑性的指令. 例如, 你想将两个值相加, 只需要写下:

编译器

我们上面写的程序在我们看来正确, 但对于计算机而言就是一串乱码, 这时, 我们就需要借助编译器将我们使用高级语言写的代码转化为计算机所能理解的机器语言指令.

我们编写的程序被存储在文本文档中, 该文件被称为源代码文件, 该文件一般要求以.c作为拓展名 (xxx.c). 编译器要将该文件转化为可执行的, 包含机器语言的文件, 一般有两个步骤. 首先, 编译器将源代码转化为机器语言, 并储存在目标文件中. 但目标文件是不完整的, 它缺少启动文件以及你所使用的库函数代码 (几乎所有程序都需要使用到C标准库里的函数, 在代码中, 你只用到了所需要的函数, 而没有真正写出这个函数的代码), 这就需要链接器来补充这两种文件. 一般编译器会自动调用链接器.

使用C语言的7个步骤

  1. 定义程序目标
  2. 设计程序
  3. 编写代码
  4. 编译
  5. 运行程序
  6. 测试和调试程序
  7. 维护和修改程序

bug和调试

在编程中我们经常会犯错误, 在程序中出现的错误一般称为bug, 在编译过程中编译器如果发现代码有问题, 将直接报错而不将源代码转化为中间文件, 读懂编译器的提示信息很重要. 查找并修复错误的过程叫做调试, 这也是使用C语言的重要一环, 以后会介绍一些调试的技巧.

数学建模论文写作方法

数学建模论文的结构

首页：论文标题＋摘要＋关键词

一、问题重述

二、问题分析

三、模型假设

四、符号说明

五、模型的建立与求解

六、模型的分析与检验

七、模型的评价、改进与推广

八、参考文献

附录

〇、首页

论文标题

大部分的论文标题形式都是：

​ “基于……方法的……模型”

摘要

摘要是对论文内容的简要的陈述，不能超过一页。

摘要三要素：

解决了什么问题；应用了什么方法；得到了什么结论

摘要的结构：

开头段（必要）

针对问题一

针对问题二

……

结尾段（大部分论文没有）

开头段

需要充分概括论文内容，两到三句即可。

第一句可以简单交代一下题目的背景；

第二句需要交代论文所做的事情；

第三句可以说一下解决该问题的实际意义。

中间段

对每个问题分别进行叙述，一般包含三要素：解决了什么问题，应用了什么方法，得到了什么结论。很多论文不写解决了什么问题，直接交代方法。

在描述使用的模型时，要结合题目本身来叙述。

回答结果时，如果答案是具体的数值，直接回答即可。如果是开放的问题，在摘要中写主要的结论即可。

关键词

关键词一般放4-6个，可以放使用到的主要模型，也可以放论文中出现次数较多，能体现论文主要内容的词（一般不会放太多）。

一、问题重述

问题重述是整理原问题，用自己的语言叙述题目，可以加上题目背景，条件等。

二、问题分析

问题分析包括题目中的信息和条件，并对题目作整体的分析，确定用什么方法建立模型，一般每个问题单独分析一段，分析过程要简明扼要，不需要放结论。

建议在文字说明的同时用图形或者图表列出思维过程，会让思路显得更清晰。

问题分析一般不超过一页，题目较多时不超过两页。

三、模型假设

模型假设要合理，且是使用模型时所必需的假设。

常见的几种假设

  1. 题目明确给出的假设条件

  2. 生活中的小概率事件

  3. 仅考虑问题中的核心因素，不考虑次要因素的影响

    ​ 注意：过于简化模型会使得论文没有优势亮点

  4. 使用的模型要求的假设

  5. 对模型中的参数形式（或者分布）进行假设

    ​ 注意：能用数据验证这些假设更好

  6. 和题目联系很紧密的一些假设，主要是为了简化模型

四、符号说明

符号说明一般在建立模型之后写，把模型中用到的符号、参数整合在表中即可（模型中临时用到的变量可以不放）

在下文中首次出现的符号，也需要进行解释，不然会降低文章的可读性

五、模型的建立与求解

优化类问题模型的建立：目标函数＋约束条件

模型求解时的注意事项
  1. 国赛中经常出现优化类问题。如果使用到了启发式（智能优化）算法，需简要写明算法步骤，并结合具体问题来阐明计算的思路。
  2. 求解的结果要突出地展现出来，如果是开放类问题要清楚地阐明和解释，配上图表更好。

六、模型的分析与检验（可以只有检验，根据需要而定）

模型的分析与检验往往是比赛的加分项，虽然能与模型的建立与求解合并，但很多优秀的论文都会单独讨论这一部分。

模型的分析

模型的分析主要有两种：灵敏性分析，误差分析

灵敏性分析：

灵敏性分析研究的是系统或模型的输出结果对系统参数变化的灵敏程度。

通用的步骤是：控制其他参数不变的情况下，改变模型中某个重要参数的值，观察输出结果的变化情况。

误差分析：

误差分析是指分析模型中误差的来源，或者估算模型中存在的误差，一般用于预测问题或者数值计算类问题。

模型的检验

这里的检验不包含应在使用模型时做的检验，比如一致性检验等，而是对模型结果的检验，最常见的是稳定性检验。（与灵敏性检验比较类似）

七、模型的评价、改进与推广（三部分不一定都要写）

模型的评价：模型的优缺点（必要）

模型的改进：针对缺点的改进方法

模型的推广：将原题的要求进行拓展，进一步讨论模型的实用性和可行性

八、参考文献。

参考文献不仅能反应真实的科学依据，还能体现出严肃的科学态度和对他人成果的尊敬。所有引用他人或公开资料的成果必须按照科技论文的规范列出参考文献，并在正文引用处予以标注。

常见的三种参考文献的表达方式
  1. 书籍的表述方式为：[编号] 作者，书名，出版地：出版社，出版年月
  2. 期刊论文：[编号] 作者，论文名，杂志名，期卷号：起止页码，出版年
  3. 网上资源（例如数据库，政府报告）：[编号] 作者，资源标题，网址，访问时间

附录

附录内容应包括支撑材料的文件列表和所用到的源程序代码，也可以包含对问题的详细证明，较大的流程图等。

如果没有程序，可以在附录中说明“本论文没有用到程序”。

支撑材料包括用于支撑模型，结果，结论的所有必要材料，至少应包含源程序、查阅的数据资料、较大篇幅的中间结果的图表等。

支撑材料使用winRAR压缩在一个文件中，后缀为RAR或ZIP，不超过20M，将其文件列表放在论文附录中。

如果没有支撑材料，可以在附录中说明“本文没有支撑材料”。

抛物线定义

​ 给定一条直线L与直线外的一点S，找到一点使得该点与给定直线和与点的距离相等，所有这样的点的集合就是抛物线。给定的直线L称为准线，给定的点S称为焦点。

​ 抛物线的第一条性质指出了抛物线是轴对称图形，并且对称轴是过焦点且垂直准线的一条直线，这条性质这里不予证明。

在下文中，均记抛物线顶点为A，焦点为S，准线与抛物线对称轴交点为X.

性质2

PP’是抛物线上的一条弦，K是PP’延长线与准线的交点，则KS平分∠PSP’的外角

[证明]

图中过P, P’作准线的垂线，Q, Q’为垂足。根据抛物线的定义，有PQ = PS, P’Q’ = P’S.

因为PQ : P’Q’ = PK : P’K = PS : SK

所以根据角平分线定理，有SK平分∠PSP’的外角。

上面的证明用到了角平分线的一个定理，下面做简要介绍及证明：

（拓展）定理1

在ΔABC中，CD为∠C的角平分线，则有CA : CB = DA : DB.

[证明]

图中DE, DE分别为过点D向CA, CB作的垂线。

因为CD是∠C的角平分线，因此有DE = DF。将DE, DF作为ΔACD和ΔBCD的高线，因为高线长度相等，所以ΔACD与ΔBCD面积之比为CA : BC.

而ΔACD与ΔBCD面积之比显然又等于AD : DB，因此有CA : CB = AD : BD.

这个命题的逆命题也是成立的，即若有CA : CB = AD : BD，则CD为∠C的角平分线，因为上面的推导过程完全可逆。

（拓展）定理2

DA为∠C外角的角平分线，研究ΔDAB与ΔDAC的面积比值，可得到AB : AC = DB : DC, 证明方法与上面类似。

命题的逆命题同样也成立，上文抛物线的性质2的证明便是用到了这个逆命题。

性质3

PN垂直于抛物线对称轴，PQ垂直于准线，则有$PN^2=4AS\cdot AN$.

[证明]

所以：$PN^2=XN^2-NS^2=(2AS-NS)^2-NS^2$

整理得：$PN^2=4AS^2-4AS\cdot NS=4AS\cdot AN$

证毕。

当N为AS外侧时，结论仍成立，证明方法类似。

性质4

当N点与S点重合时，即过S作对称轴垂线交抛物线于P，由上面的结论得$PS=2AS$

性质5

过P作抛物线切线，交准线于点K，则有PS⊥KS

[证明]

设抛物线上另有一点P’，根据性质2，KS平分∠PSP’的外角。现在令P‘无限靠近P，则PP’也无限接近于过P点的切线，∠PSP’极限为0，∠PSK极限为$\frac {\pi}{2}$ .

由三角形全等性也易得P为∠SPQ的角平分线
