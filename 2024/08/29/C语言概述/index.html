C语言概述

首先来看一个简单的程序, 来初步学习一下C语言

这是一条预处理指令, C 编译器在编译之前会首先处理预处理指令. 这条语句的作用相当于将 stdio.h 的文件内容直接复制粘贴过来, 替换掉 #include 这条指令.

stdio.h 文件是一个头文件 (header, 文件拓展名为 .h). 通常, 在 C 程序顶端的信息集合被称为头文件, 包含着编译器为编译程序可能需要用到的信息, 包括声明变量以及声明函数. 在 stdio.h 文件中, 包含着 printf() 的函数声明, 这是我们需要的, 因此这里我们需要使用这条语句.

事实上, stdio.h 被称为标准输入/输出头文件, 它包含 C 函数库中输入/输出函数的声明, 在绝大多数需要输入输出的程序中都需要用到它.

在 C 程序中你可以定义任何函数, 但记住, main() 函数总是程序首先执行的函数, 看来 main 这个普通的名字对编译器有着特殊的意义 XD.

C 程序的基本模块是函数, 每个函数有着各种各样不同的功能, 而 main() 函数总是最先被执行的函数, 它是程序的基本框架.

圆括号 ‘( )’ 是函数的标志, 圆括号前面的字符称为函数名, 例如在这里的函数名字为 main. 括号中的内容表示需要输入函数的内容. 这里 void 表示空 (即不需要输入).

前面的 int 是 C 语言的关键词, 表示 main 函数返回值为整形, 在后面章节再讨论函数返回值的问题.

后面的花括号中即为函数的内容. (必须使用花括号 ‘{}’)

总之, int main(void) 为书写 mian() 函数的标准格式, 需要按规定这样书写.

这行代码叫做声明, 声明是 C 最重要的特征之一. 在其他语言中, 你可能不需要这行代码就能直接使用一个变量, 但 C 语言严格化了使用变量这个操作, 对于以简便灵活著称的 C 语言, 这么做一定有道理.

声明中的 int 告诉了计算机我要使用一个整形变量, 计算机便在内存中的某个位置划分出整形所需要大小的内存区域, 并将该内存区域命名为 num, 以后每当程序使用 num 这个变量, 就会查取这个内存区域所存储的值.

变量, 顾名思义其值可以变动, 这往往通过赋值操作完成, 使用赋值运算符 “=”

在写 C 程序时, 往往将所有变量的声明放在函数最开始的位置, 这样便于理清整个程序的思路.

多个变量的声明也可以写在一起, 用逗号隔开

printf()函数

printf()是标准输出函数, 这个函数会查看双引号中的内容, 并将其打印在一个窗口上. 除了一些能明确输入的字符, 还有一些不能直接输入的字符 (转义序列), 比如换行符. 输入\n 能表示这个符号, 使得光标换行再继续输入.

第三条 printf 语句不仅打印了一系列我们输入的字符, 还打印了 num 变量的值. 在打印变量的值时, 计算机会用变量的内容替换掉 %d. %d 中的 d 告诉计算机, 我想用十进制整数的形式来打印出 num 的值, 以后还会见到更多变量的输出形式.

上面说过, int main(void) 中的 int 表示 main() 函数的返回值为整形, 那返回值为多少呢? 使用 return 语句来返回函数的值, 这里返回的值为0. 对于有返回值的函数 (函数名前的返回值类型不是 void 的函数), 都需要 return 语句来返回函数值.

这里 main() 函数的返回值其实没有太大的含义, 但 C 语言要求如此, 一般都会在 main() 函数主体最后加上 return 0. (如果没有 return 语句, 函数默认返回值也是0, 但其他有返回值的函数返回值都是有意义的, 都需要最后加上 return 语句, 这里为了养成好习惯, 所以在 main() 函数最后也加上)

注释有两种形式, 可以用 / … / 将注释内容括起来, 相当于括号, 可以跨行使用. 另一种是 // , 注释内容放于其后, 只能单行使用.

这是函数原型语句, 或者叫函数的声明. 它告诉编译器本程序会用到这一个函数, 并告诉如何使用该函数 (输入参数数据类型以及返回值类型). C 语言规定, 使用任何函数都需要进行函数声明. 那为什么我们没有对 printf() 函数进行声明呢. 上面提到过, printf() 的声明已包含在 stdio.h 文件中, 我们使用 #include 语句就相当于进行了函数声明.

定义函数

函数是 C 程序的基本模块, 每个函数都有各种各样的功能. 函数由函数头和函数体组成, 函数头包括返回值类型, 函数名以及传入函数的信息类型, 函数体即为花括号部分. 函数体由一系列语句 (如运算表达式, 赋值表达式等) 和声明(变量的声明) 组成.

分号是一条语句和一条声明的一部分, 当编译器读到分号时, 编译器明白这是一条语句, 写程序一定不要忘记分号. (语句以分号为分隔, 即使你将所有语句写在同一行, 只要加上了分号, 代码也能运行, 只是会不那么美观. 预处理指令以换行符为分隔, 不需要分号) 函数声明也是声明, 也是一条语句, 需要使用分号. 定义函数时, 函数头与函数声明很类似, 但函数头后面不能使用分号, 因为它不是一条语句.

我们定义的 apple 函数返回值类型为 void, 即没有返回值, 因此没有 return 语句.

程序的调试

程序调试过程即为发现程序错误的过程. 如果程序有语法错误, 编译器能够发现并指出.但如果发生语义错误, 编译器则不能发现.

如果在编译过程中发生错误, 根据编译器的提示检查代码对应行, 改正语法错误.

如果编译成功, 但输出结果和预期不符 (即发生语义错误), 对于简单的程序, 可以逐条分析代码, 模拟变量变化过程, 分析变量在哪一步发生了问题. 对于较为复杂的程序, 可以利用编译器自带的调试工具. 调试工具能使代码运行至指定位置, 并逐条运行代码, 在运行过程中你可以查看变量的变化过程.

在学习 C 语言时, 犯错是不可避免的, 不要灰心, 这些都能成为你宝贵的经验!
